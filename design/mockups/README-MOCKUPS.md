# Nitin Kotcherlakota Portfolio Mockups — Deep Purple

These images are visual references for Claude Code. They are not production assets and should not be embedded directly into the website.

## Visual direction

- Deep purple is the primary accent.
- Use near-black charcoal for dark surfaces rather than pure black.
- Use warm off-white for light sections.
- Keep gradients subtle and localized.
- Use large readable typography, fine borders, generous spacing, and minimal shadows.
- Home Journey is the only active flagship case study.
- Coral, Lab, Notes, Ask About My Work, and future projects must remain clearly marked **Coming Soon**.
- The About mockup contains a generated portrait. Do not use it as Nitin's portrait. Replace it with a real image or a neutral placeholder.
- Financial dashboards contain conceptual sample data only. Never reproduce personal balances, transactions, or fake public metrics.
